# Why the earlier draft had only 17 results

The earlier local `Greece_Atlas_Prompt_AM` artifact contains 693 offices, 2,081 events and only 17 result rows. Its local events were generated across three cycle dates for the current register, while its numeric results were limited to selected national/European rows. It contains no local/regional vote vectors and no historical office rows. That was an incomplete research artifact, not the requested historical-results pack.

The rebuild reads actual authority registers and returns for four cycles. It adds the omitted 2010 cycle; retains all losing as well as winning slate/head candidates; creates runoffs only from authority-specific evidence; separates five abolished municipalities; and documents the President as an indirect office. The previous result rows are superseded by retained, sourced values and should not be merged blindly into this pack.

The previous artifact was left unchanged. No production dataset was changed. Remaining historic source gaps are listed explicitly instead of being obscured by the increased count.
