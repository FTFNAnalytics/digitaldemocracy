# Source inventory and integrity

`Source_Inventory.json` supplies the exact URL, publisher, retained path, byte count, SHA-256 and hash semantics for each retained source. `data/source_aliases.json` resolves law/article references used by register and event rows. Original workbooks are retained; official web extractions are clearly distinguished from original-byte downloads. All retrievals belong to the 29 September 2026 research snapshot.

The authoritative current roster is SERVEL’s August 2026 workbook, checked against SUBDERE’s 2018 CUT register. TRICEL certified summaries take precedence over preliminary returns; SERVEL historical certification remains explicitly qualified where not independently verified. Current register completeness is independent of historical result completeness.
