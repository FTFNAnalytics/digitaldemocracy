## Source and conversion contract

Paths are relative to pack root. `C`=data/research/slovenia/country.json; `O`=office-register.json; `G`=geography.json; `E`=events.json; `Rr`=results.json; `Pp`=proceedings.json; `S`=sources.json; `X`=identity-crosswalk.json; `K`=counts.json, all in that research folder. `T`=schemas/atlas/tiers/slovenia.json; `I`=Slovenia_Input_Inventory.json; `V`=Slovenia_Identity_Vectors.json, both in this docs folder. Dot paths denote object keys; array elements have exact JSON pointers in V and each row's origins. L=`country-package-slovenia`, N=`cdd-observatory-v1`, R=I.candidate_release_id, a draft fingerprint candidate only.

The maps consume the normalized documentary JSON, with every claim bound to immutable retained primary bytes. Full raw sources survive as retained_input; `source-projection.json` declares which bytes contributed normalized claims. No unknown upstream key is dropped: JSON `raw_json` retains row, origins and source properties; full HTML/PDF/JS stays a checksummed artifact with payload_json=NULL. No HTML/JS is executed. No invented metric, geometry, control or polling table is added. Empty party-mappings/unresolved/successor arrays are explicit.
