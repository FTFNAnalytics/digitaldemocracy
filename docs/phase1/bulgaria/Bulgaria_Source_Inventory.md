# Bulgaria — source inventory and hash semantics

The machine-readable `Bulgaria_Source_Inventory.json` is authoritative. Source IDs preserve P's original catalogue; new IDs use the BI prefix. The manifest hashes every saved file, including unchanged P evidence. No checksum is invented for an inaccessible original webpage.

`file_sha256` hashes the exact saved local bytes. `remote_original_sha256=null` means the original response bytes were not downloaded. Indexed/extracted text may omit lines or include search excerpts; its hash is an extraction hash. Raw EP HTML is identified separately. `sources/Direct_Retrieval_Log.json` records direct-download successes/errors without treating errors as zero evidence.

P's 3,973 source-catalogue entries remain citations with original evidence grades and checked dates. They were not all fetched anew.
