## How to review

- `Georgia_Review.xlsx` gives filtered office, tier, event, result, calendar, hold and source sheets. JSONL files in `data/` are the lossless structured research records; CSV views are in `tables/`. Empty numeric CSV/XLSX cells represent JSON null, never zero.
- `Identity_Rules.md`, `Research_Gaps.md`, and `History_Coverage.md` explain boundaries, selection eras and incomplete evidence.
- `Field_Map_223.md`, `tables/field_map_223.csv` and `contracts/columns.json` preserve the inherited 223-field documentary contract. They are not executable database mappings.
- `sources/source_inventory.jsonl`, `Source_Inventory.md` and retained public source bytes provide URLs, SHA-256 hashes and retrieval status. The CEC/IFES historical compendium is referenced by URL and original retrieval digest; its copyrighted book PDF is not redistributed. GEDA data are credited to David Sichinava under the archive's declared CC-BY-4.0 terms, pinned to commit 18db7c7aaeb60ef3a81e5e8c41793ac339046859.
- `Acceptance_Examples.md`, `SHA256SUMS`, `validation-report.json` and the offline `validate.py` make the pack reviewable. Run `python validate.py` from any directory; the validator reads this pack only and makes no network or application writes.

The prior BE ZIP itself was unavailable for comparison. BG uses the user-restated gates; no old BE identifiers are invented. No approval or publication is implied by successful structural validation.
