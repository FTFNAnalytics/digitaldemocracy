## Publication contract

Every Hungary row owns `(lineage_id,release_id)`. A publication is a set of lineage releases. Unchanged input → new durable attempt, same Hungary release; other lineage release IDs/rows remain unchanged. Hash all research inputs, tier bytes, accepted overrides (none here), adapter/method/schema versions and both migration hashes. Failed FK/fixture/guard/date/domain check rejects staging and leaves last good serving file. Copy to same-filesystem stage, validate, checkpoint WAL, close handles, fsync database/directory as protocol requires, atomic rename, durable receipt/attempt transitions. No execution of that protocol occurred here.

Incomplete refresh ≠ delete: retain omitted office and its owned evidence; a partial update needs a versioned cumulative effective-input manifest before fingerprinting. Missing evidence tokens go to unresolved_evidence; a purported resolved source with absent FK fails closed. Original allegations never become fabricated catalogue IDs.
